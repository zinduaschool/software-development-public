# 03. React Frontend Development Course
Official Curriculum for React FrontEnd Development Course in the Frontend Development Program.
- **Course Objective:** Provide a structured learning path for mastering React, from fundamentals to real-world applications.
- **Skills to be learned:**  JSX, Components, Props, State Management, React Hooks, Routing, API Integration, Performance Optimization, Testing, and Deployment.

## Curriculum Breakdown
### Week 1: React Fundamentals
> **Objective:** Build your first React interfaces: learners will be able to explain how React and single-page applications work, build components with JSX and props, manage state and events, and render lists and conditional content.
#### Lesson 1: Introduction to React
- What is React? Key features and benefits.
- Introduction to Single Page Applications (SPAs).
- Setting up the development environment (Node.js, npm, etc.).
- Install and run a React app using vite.
- (Daily Challenge: Create your first React app and display "Hello, World!")
  
#### Lesson 2: JSX and Components
- Understanding JSX and its syntax.
- Creating Functional and Class Components.
- Passing data with props.
- (Daily Challenge: Build a component that dynamically takes user input and displays it.)

#### Lesson 3: State and Events
- Managing component state with useState.
- Handling events in React.
- (Daily Challenge: Create a button that toggles text visibility.)
  
#### Lesson 4: Rendering and Lists
- Conditional rendering.
- Rendering lists with .map().
- Using keys in lists.
- (Daily Challenge: Display a list of users dynamically.)

- **Projects:** Create a React app that renders a list of books, movies, or any data of your choice. Create separate components for the list and the individual items
  
### Week 2: Intermediate React
> **Objective:** Build multi-page, stateful applications: learners will be able to handle forms with hooks, style components, share state with the Context API, and add client-side routing and navigation.
#### Lesson 1 Forms and Hooks
- Building forms and using controlled components.
- Introduction to React Hooks (useState, useEffect).
- (Daily Challenge: Create a login form that handles user input.)
  
#### Lesson 2: Styling in React
- Inline styling and CSS Modules.
- Styled Components.
- Integrating a library like TailwindCSS or Material-UI.
- (Daily Challenge: Style a button using different methods.)

#### Lesson 3: State Management with Context API
- Context API for global state management.
- Prop drilling and how Context solves it.
- (Daily Challenge: Implement dark mode using Context API.)
  
#### Lesson 4: Routing and Navigation
- Setting up React Router.
- Creating routes and linking pages.
- Dynamic and nested routing.
- (Daily Challenge: Build a navigation menu with multiple pages.)
  
- **Projects:** Develop a multi-page portfolio website with navigation and theme switching.
  
### Week 3: Advanced React
> **Objective:** Connect to real data and keep it fast and reliable: learners will be able to integrate a back-end API, optimise rendering performance, and test components and user flows.
#### Lesson 1: Backend Integration
- Fetching data with fetch and Axios.
- Displaying API data in components.
- Error handling in data fetching.
- (Daily Challenge: Fetch and display data from a public API.)

#### Lesson 2: Performance Optimization
- Optimizing components with React.memo and useMemo.
- Using useCallback to optimize functions.
- Lazy loading and code splitting.
- (Daily Challenge: Optimize an existing component to reduce re-renders.)

#### Lesson 3: Testing React Applications
- Introduction to Jest and React Testing Library.
- Writing unit tests for components.

#### Lesson 4: Testing React Application
- Testing user interactions.
- (Daily Challenge: Write a test case for a form validation function.)

- **Projects:** Build a weather app that fetches and displays live weather data.

### Week 4: Building and Deploying a Real-World Application
> **Objective:** Ship a production-ready application: learners will be able to manage complex state with Redux, implement end-to-end features, and deploy an app following best practices.
#### Lesson 1: State Management with Redux
- Introduction to Redux.
- Using Redux Toolkit for state management.
- (Daily Challenge: Implement a counter using Redux.)

#### Lesson 2: Implementing Features
- Implement authentication (optional).
- Add CRUD functionality.
- (Daily Challenge: Add user login or CRUD operations.)

#### Lesson 3: Deployment and Best Practices
- Preparing the app for production.
- Deployment using Vercel, Netlify, or GitHub Pages.
- Best practices in React development.
- (Daily Challenge: Deploy your project and share the link.)

- **Projects:** Build a fully functional to-do list app that integrates the Context API for global state management and fetches tasks from a remote API.)

### Week 5: Capstone Project
> **Objective:** Deliver a complete React application: learners will be able to plan, build, deploy and present a capstone project that applies the full course.
**Capstone Projects:** To-Do App
- E-commerce Website
- Blog Platform
- Social Media Dashboard
- Weather App
  
### **Optional Bonus Lessons:**
- Server-side rendering with Next.js.
- Progressive Web Apps (PWAs).
- Animations with Framer Motion.
  
### **Further Resources:**
- Official React documentation.
- Online tutorials and communities.
