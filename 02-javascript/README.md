# 02. JavaScript Programming Course
Official Curriculum for JavaScript Programming Course in the Software Development Program.

- **Course Description:** A 5-week course that takes learners from their first script to interactive, tested web applications. Learners build progressively — core syntax, types and control flow, then the DOM, events and asynchronous programming, then modern ES6+ syntax, functional and object-oriented programming and testing, then jQuery and AJAX — before completing a capstone project.

- **Course Objective:** Equip learners to write modern, tested JavaScript that manipulates the DOM, handles events, fetches data asynchronously and is structured with functional and object-oriented patterns.

- **Skills to be learned:** JavaScript (ES6+), Node.js, DOM manipulation, events & event propagation, callbacks, promises & async/await, Fetch API, error handling, destructuring, spread/rest, array methods, object-oriented programming, Jest testing, jQuery, AJAX
